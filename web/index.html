Features

Everything you need to follow the match.

The widget pulls live data from public endpoints so there is nothing to configure. Just install and go.

◴

Live scores & fixtures

Matches update automatically from ESPN's public API. Upcoming games, live scores, and full-time results at a glance.

◉

Animated pixel mascot

A small creature lives on your widget. It reacts to match events: celebration on goals, idle between games, and sleep when nothing is on.

◆

Three size modes

Double-click to cycle between Wide, Compact, and Mini. Each mode preserves the key information while adapting to your screen space.

◵

Match panel & stats

Expand the widget to see upcoming fixtures, recent results, head-to-head records, and win probability predictions.

⚙

Built-in AI assistant

Ask tactical questions or get match analysis using your own Gemini or OpenRouter key. The key stays on your machine.

♥

Customisable appearance

Change colours, gradients, and corner radius. Or open the pixel editor and draw your own mascot sprite.

↻

Floating notifications

Goals, kickoffs, and full-time events pop up as a floating toast window with the correct mascot animation and a chime sound.

☰

API status & credits

Separate windows show DeepSeek API health with a 30-day history grid and a token credit tracker with low-balance alerts.

↺

Automatic updates

The app checks for new versions in the background and notifies you when an update is available. One click takes you to the download page.
